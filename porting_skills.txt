SKILL: ALTCPM PORTING ANALYZER
VERSION: 0.4

PURPOSE
-------

Analyze CP/M assembly source code and identify modifications required
to port software from standard CP/M (BASE=0000h) to ALTCPM
(BASE=4200h).

This skill does NOT automatically modify source code.

Its purpose is to classify findings as:

  [OK]      Definite conversion
  [CHECK]   Requires verification
  [WARN]    Potential problem
  [INFO]    Useful information


FUNDAMENTAL CONCEPTS
--------------------

Standard CP/M:

  BOOT   = 0000h
  BDOS   = 0005h
  FCB1   = 005Ch
  FCB2   = 006Ch
  DMA    = 0080h
  TPA    = 0100h

ALTCPM:

  BOOT   = 4200h
  BDOS   = 4205h
  FCB1   = 425Ch
  FCB2   = 426Ch
  DMA    = 4280h
  TPA    = 4300h

General rule:

  new_address = old_address + 4200h


------------------------------------------------------------------

RULE A1 - SYMBOLIC ZERO PAGE
----------------------------

Pattern:

  BOOT EQU 0000H
  BDOS EQU 0005H
  FCB1 EQU 005CH
  ...

and subsequent symbolic usage:

  CALL BDOS
  JP BOOT
  LD A,(FCB1)

Action:

  Update only the EQU definitions.

Classification:

  [OK]


------------------------------------------------------------------

RULE A2 - CONSTANT OFFSET TRANSLATION
-------------------------------------

Verify that CP/M system addresses have been translated
by +4200h.

Examples:

  0000h -> 4200h
  0005h -> 4205h
  005Ch -> 425Ch
  0080h -> 4280h
  0100h -> 4300h

Classification:

  [OK]


------------------------------------------------------------------

RULE A3 - PARAMETERIZED ZERO PAGE
---------------------------------

Pattern:

  BASE EQU xxxxH

  WBOOT EQU BASE+0000H
  BDOS  EQU BASE+0005H
  FCB   EQU BASE+005CH
  DMA   EQU BASE+0080H
  TPA   EQU BASE+0100H

Example:

  BASE EQU 6000H

  WBOOT EQU BASE+0000H
  BDOS  EQU BASE+0005H
  TPA   EQU BASE+0100H

Action:

  No action required.

The source is already rebase-friendly.

Classification:

  [OK]


------------------------------------------------------------------

RULE A4 - COM PROGRAM LOAD ADDRESS
----------------------------------

Pattern:

  ORG 100H

or explicit references to the CP/M TPA entry:

  LXI H,100H
  LXI D,100H
  JMP 100H
  CALL 100H

Action:

  Verify whether the reference represents
  the CP/M COM load address.

Typical conversion:

  0100h -> 4300h

Classification:

  [OK]


------------------------------------------------------------------

RULE B1 - HARD-CODED ABSOLUTE SYSTEM ADDRESSES
----------------------------------------------

Search for direct references to:

  0000h    WBOOT entry point
  0001h    WBOOT vector address byte
  0002h    WBOOT vector address byte
  0003h    IOBYTE
  0004h    Current/default disk
  0005h    BDOS entry point
  0006h    BDOS vector low byte
  0007h    BDOS vector high byte

  005Ch    Default FCB #1
  006Ch    Default FCB #2
  0080h    Default DMA buffer / command tail

Classification:

  [OK]


------------------------------------------------------------------

RULE B2 - FCB INTERNAL FIELD ACCESS
-----------------------------------

Pattern:

  Direct access inside default FCB areas:

    005Dh-006Bh
    006Dh-007Bh

Examples:

  LDA 65H
  STA 67H
  LHLD 70H

Important:

  Do NOT automatically translate these
  addresses by +4200h.

Some ALTCPM environments preserve CP/M-compatible
access to default FCB contents at historical
addresses.

Action:

  Manual verification required.

Classification:

  [CHECK]


------------------------------------------------------------------

RULE B3 - COMMAND TAIL AREA ACCESS
----------------------------------

Pattern:

  Direct references in range:

    0080h - 00FFh

Examples:

  LDA 80H
  LDA 81H
  STA 90H
  LHLD 82H

Notes:

  The area may be used as:

    - command tail
    - default DMA buffer
    - transient workspace

Action:

  Verify actual usage before conversion.

Classification:

  [CHECK]


------------------------------------------------------------------

RULE B4 - WARM BOOT TRANSFERS
-----------------------------

Pattern:

  JMP 0
  JMP 0000H
  CALL 0
  CALL 0000H

Purpose:

  Return to CP/M using the warm boot entry.

Typical conversion:

  0000h -> 4200h

Examples:

  JMP 0
      becomes
  JMP 4200H

Classification:

  [OK]


------------------------------------------------------------------

RULE B5 - TPA ADDRESS REFERENCES
--------------------------------

Pattern:

  Direct references to:

    0100h

Examples:

  LXI H,100H
  SHLD STARTADR
  CALL 100H

Purpose:

  Detect assumptions that a COM program
  is loaded at the standard CP/M transient
  program area.

Typical conversion:

  0100h -> 4300h

Action:

  Verify intent and convert when the address
  represents the COM load location.

Classification:

  [CHECK]


------------------------------------------------------------------

RULE C1 - DEFAULT DMA ASSUMPTIONS
---------------------------------

Pattern:

  BDOS file operations followed by direct
  accesses to DMA memory.

Examples:

  MVI C,20
  CALL BDOS

  LXI D,80H

or

  MVI C,21
  CALL BDOS

  LXI H,80H

Purpose:

  Detect software relying on the default
  DMA buffer location.

Action:

  Verify that DMA relocation to 4280h
  is correctly handled.

Classification:

  [INFO]


------------------------------------------------------------------

RULE C2 - EXPLICIT SETDMA OPERATIONS
------------------------------------

Pattern:

  Explicit BDOS function 26 (SETDMA) calls:

    MVI C,26
    LXI D,80H
    CALL BDOS

or:

    MVI C,26
    LXI D,0080H
    CALL BDOS

Purpose:

  Detect programs that explicitly select
  the standard CP/M DMA buffer.

Typical conversion:

    LXI D,80H

becomes

    LXI D,4280H

Action:

  Verify that the DMA address passed to
  BDOS function 26 has been relocated
  to the ALTCPM DMA area.

Classification:

  [OK]


------------------------------------------------------------------

RULE C3 - DIRECTORY GEOMETRY ASSUMPTIONS
----------------------------------------

Pattern:

  Direct BIOS disk access combined with
  hard-coded directory parameters.

Examples:

    TRACK  DB 2
    DIRMAX DB 16

or:

    CALL SELDSK
    CALL SETTRK
    CALL SETSEC
    CALL READ

Purpose:

  Detect applications that access directory
  sectors directly through BIOS functions and
  therefore assume specific disk geometry,
  directory location, or reserved boot area
  layout.

Notes:

  Such assumptions are independent of the
  ALTCPM 4200h relocation.

  A program may require adjustment of:

    - directory start track
    - reserved boot tracks
    - directory size
    - sector numbering

Action:

  Verify that the target ALTCPM system uses
  compatible disk geometry.

Classification:

  [CHECK]


------------------------------------------------------------------

RULE D1 - RET TO CP/M
---------------------

Pattern:

  RET executed from a transient program
  after restoring the original stack.

Examples:

  LHLD OLDSTK
  SPHL
  RET

Purpose:

  Standard CP/M applications frequently
  terminate by returning through the CCP
  entry stack frame.

Action:

  Usually no conversion required.

Classification:

  [INFO]


------------------------------------------------------------------

KNOWN VALID CONVERSIONS
-----------------------

Observed and validated in real ports:

  BDOS EQU 5
      -> BDOS EQU 4205H

  ORG 100H
      -> ORG 4300H

  LXI D,5CH
      -> LXI D,425CH

  LXI D,80H
      -> LXI D,4280H

  LXI H,80H
      -> LXI H,4280H

  JMP 0
      -> JMP 4200H

  LXI H,100H
      -> LXI H,4300H


END OF SKILL
