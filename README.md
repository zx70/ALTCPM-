# ALTCPM-
A collection of tools, code and binaries pertaining to the rare implementations of CP/M systems with the TPA positioned differently than 0100h (usually 4300h)

Such configuration was first marketed by Lifeboat Associates to extend their software portfolio capability and run on computers not equipped with a memory mapper.  Most of those computers could be expanded with a memory mapper (a.k.a. "org 0" or "allram" mode)


NOTE
The included programs have been converted with mixed techniques, suprisingly similar to the ones originally used around 1980.
Originally this project focused on material found in ancient disks and original code found in BBS backups.
Much more can be obtained from repositories like this one:   https://github.com/cm68/cirsovius/tree/master/Disassembler/Gesammeltes
